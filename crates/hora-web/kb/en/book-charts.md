# The book's charts

This appendix lists all 96 numbered charts of *Vedic Astrology: An Integrated Approach*, in the book's order, so you can open any of them while you read. Follow a chart's link and hora calculates it from the book's data with Lahiri ayanamsa, the mean node and the upper limb rising. Charts 49, 50 and 51 open with True Chitra instead, the ayanamsa nearest the positions the book prints for them.

A few things to know when you compare hora's page with the book:

- A link opens the [rasi chart](/en/kb/chart) and the navamsa. Where the book draws another [varga chakra](/en/kb/varga-chakra), the row names it, and you can choose it on the chart page.
- Some numbers appear twice, because the book prints two charts under that number, such as a birth and a transit.
- Where the book shows the same data again, the row says which chart it repeats, and both links open the same chart.
- The book prints times to the minute, but its positions fit a time with seconds. Where that is so, the link includes the seconds, so the time can look a little later than the one in the book.
- A chart has no link when the book prints too little to calculate it, and its row says what is missing.
